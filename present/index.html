Present a paper

MTech, PhD and RAs: pick a paper from one of the conference reading lists, sign up for a slot, and present it with the shared slide template. Two things below — a sign-up sheet and a slide deck template.

1 · Sign up to present

A starter sign-up sheet with open slots is in this repo: signup-template.csv. Columns: slot date, venue, paper title + link, presenter, role, the lab project it connects to, status, slides link, notes.

Turn it into a shared Google Sheet (2 min)

  1. Open sheets.new → File → Import → Upload → choose signup-template.csv → Replace spreadsheet.
  2. Share → "Anyone with the link" → Editor, so students can add their name to a row.
  3. Optional: Data → Data validation on Role (MTech / PhD / RA) and Status (Open / Taken / Done).
  4. Paste the sheet URL back here (edit present/index.html) so everyone finds it.
Download signup-template.csv ↓

Prefer no edit-collisions? Make a Google Form (Name, Role, Paper title + link, Preferred date) with responses feeding a Sheet — cleaner for sign-ups, same columns.

2 · Slide deck template

A reusable 10-slide template — Title, TL;DR, Problem, Method, Results, Strengths, Limitations, Relevance to our lab, Discussion, References. The "Relevance to our lab" slide is the one that matters most: say which project it touches and what concretely to try.

★ template

paper-presentation-template.pptx

Works in PowerPoint, Keynote, and Google Slides. For Google Slides: slides.new → File → Import slides → upload the .pptx, or upload to Drive and "Open with Google Slides". Then Make a copy per talk and fill the <placeholders>.

How a good 15-minute reading-group talk goes

TL;DR first (30s) → problem & why it's hard (2m) → the one key idea + main figure (4m) → results & what's convincing/suspicious (3m) → relevance to our lab: which project, what to try (3m) → limitations & discussion (3m). Read the abstract before the room; don't read equations aloud.
